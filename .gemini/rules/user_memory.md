# User Memory and Goals

## Facts About the User
- **Language Preference**: The user communicates and requires all outputs, documents, and deliverables strictly in the requested language, not only Latvian.
- **Project Domain**: Developing and managing a SPA (Single Page Application) called "Splendid Darwin", which acts as a Spa/Salon booking system. It handles specialists, scheduling, client feedback, and appointments (e.g., David Green, Hot Stone Massage).
- **Current Focus / Goals**: The user is actively studying and working on data architecture, systems thinking, and data flow modernization tasks (e.g., assignments on moving from simple Excel/Sheets to structured databases, SQL analytics, and modern data stacks).
- **Problem-Solving Style**: The user prefers practical, realistic, and proportional IT solutions. Strongly dislikes over-engineering (e.g., proposing Data Lakes or complex cloud infrastructures for small datasets). Values clear, business-impact-focused explanations over heavy technical jargon.
- **Deliverable Preferences**: The user frequently requests deliverables in the form of a **PDF document**. The preferred workflow is generating a well-structured Markdown file and converting it using `md-to-pdf`. Documents must almost always include Mermaid diagrams and a provided AI prompt for diagram enhancement.
